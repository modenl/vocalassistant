# 声乐练习台 VocalLab

在浏览器里用麦克风听你唱歌，只做**测得准**的判断，并告诉你下一步练什么。纯前端，无需构建；数据只保存在本机浏览器（IndexedDB）。

## 运行

```bash
python3 tools/serve.py        # → http://localhost:8765
```

麦克风需要安全环境（`localhost` 或 https）。建议关闭耳机 / 系统降噪，离麦克风 20–30 cm。

## 功能

| 模块 | 内容 |
|---|---|
| 唱一段看问题 | 实时音高轨迹（绿 = 准、黄 = 略偏、红 = 不准、灰 = 滑音；⚡ 断档、↘ 句尾掉音、↗ 挑音）、当前音与音分表、五维评分（雷达图 + 总分）；唱完给出“最需要练的 3 件事”和对应课程 |
| 基础课程 | 7 课 18 步：音准、长音与气息（含“一口气唱多长”）、滑音不断、音量控制、不喊唱、颤音、咽音。每步有参考音、目标线和一句话的通过标准，程序自动判定并打 0–100 分 |
| 音准训练 | 每轮 10 题自动出题：随机跟唱、听一唱二（听 do 唱 mi / sol / la…）、回声短句（3–4 个音）。每题“听 → 心里唱一遍 → 唱”，马上告诉你偏高 / 偏低多少音分；判定线随水平收紧，唱稳后改成唱完才显示音高线；每轮给出小结（整体偏高 / 偏低、大跳唱小、上行 / 下行、哪个音区最不准） |
| 声音显微镜 | 同时看波形（时域）、频谱（F0、谐波包络、F1/F2、2–4 kHz 共鸣，和跟唱、咽音课用同一个组件）、声谱图，以及根据声音推测的声道侧视示意图（舌位、咽腔收窄、软腭、喉位），实时列出问题并用编号箭头指到示意图上；可录 6 秒普通唱法滑音作为基准（之后任何音高都能和同一音高的普通唱法比），带咽音计；共振峰 F1–F5 图（元音图 + 每个发音一行的“指纹”，可“记下这个音”并排比较，附标准元音）；也能分析录音文件 |
| 历史记录 | 每次的五维评分、完整音高轨迹与录音同步回放；旧记录打开时按最新规则重新分析 |
| 设置 | 语言（中文 / English，默认跟随系统和浏览器）、声部（只决定练习音的音区）、参考音（人声“啊” / 钢琴）、A4、麦克风、噪声门限、数据导出 / 清空 |

## 网址

每个页面都有自己的网址，可以收藏、分享，刷新后停在原处，浏览器前进 / 后退可用：`#/live`（唱一段看问题）、`#/lessons`、`#/lessons/<课程>/<第几步>`（如 `#/lessons/twang/2`）、`#/gym`、`#/scope`、`#/history`、`#/history/<记录 id>`、`#/settings`。课程、音准训练和声音显微镜都实时显示当前唱的音（音名、偏高 / 偏低多少音分、频率）。

## 五维评分（不需要原唱或乐谱）

音准按“你自己的调”判断。每一项都有公开的计分规则（界面里“评分：…”），维度分 = 各项加权平均（有一项 < 60 时，该维度最多 74 分），总分 = 已判断维度的平均（至少 3 维、唱满 15 秒才出总分）。数据不够的项目不计分，边唱边显示进度和“还差：再唱 N 个音 / 约 N 秒”；唱够了但这类演唱判断不了的（如环境太吵测不了共鸣）显示“无法判断”。

| 维度 | 检查 | 怎么测 | 计分（满分 / 75 / 60） |
|---|---|---|---|
| 音准 | 相对音准（×3） | 稳定的音相对你自己（±8 s 局部）的十二平均律格子的偏差，±25 音分内算准 | 唱准比例即分数 |
| | 整体偏移（×1） | 6 秒一窗（每 3 秒）的整体音高（圆周平均，窗内的音要对得上同一个调），窗与窗之间展开，最后几窗对最初几窗：越唱越低 / 高 | ≤ 10 / 30 / 60 音分 |
| 共鸣 | 穿透力（×2） | 歌手共振峰：每个唱着的帧里 0–2 kHz 最强谐波比 2–4 kHz 最强谐波高多少（歌唱功率比 SPR，Omori 1996），取中位数；越小越“有芯”。歌剧演员 11–30 dB，最好的约 15 dB。只用 2–4 kHz 峰值比该频段底噪（全程第 10 百分位）高 ≥ 12 dB 的帧，合格帧不到一半时判为“底噪太高，不判断”。挤卡不会让它变好 | ≤ 15 / 21 / 26 dB |
| | 高音共鸣（×1） | 同样的帧里，音域上三分之一比中间三分之一的 SPR 大多少（往高唱丢了“芯”：变薄、发虚或在喊），唱的音域 ≥ 5 个半音才判断 | ≤ 3 / 6 / 9 dB |
| 气息 | 长音稳定 | ≥ 0.8 s 的长音里，去掉颤音后的音高漂移（P10–P90） | ≤ 15 / 35 / 60 音分 |
| | 句尾掉音 | 乐句最后一个长音（≥ 0.7 s，后面停顿 ≥ 0.25 s）结束前 0.22–0.05 s 的平均音高比音身低 ≥ 30 音分；超过一个半音的快速下滑算风格（fall-off） | 掉音比例 0 / 20 % / 35 % |
| 技巧 | 断档 / 破音 | 连续发声中音高突跳 ≥ 1.5 半音并保持，同时音量反向阶跃 ≥ 5 dB（M2 比 M1 弱 8–10 dB），没有辅音式凹陷；只在换声区（较高的音 ≥ A3）判断，更低处的跳进是旋律 | 每分钟 0 / 0.5 / 2 次 |
| | 喊唱 | 音量对音高的回归斜率（自然上升约 0.5–0.8 dB/半音）+ 高低音量差 | ≤ 0.8 / 1.2 / 1.6 dB/半音 |
| | 挑音 | 停顿后开口的音：开头 60 ms 比稳定后的音低 ≥ 80 音分（≤ 3 半音），用 ≥ 0.1 s 才到位 | 比例 ≤ 5 % / 25 % / 40 % |
| | 颤音 | ≥ 0.75 s 长音的音高频谱：速率、幅度、规律性；直音不算问题 | 有毛病的比例 0 / 30 % / 50 % |
| 表现力 | 强弱对比 | 乐句（停顿 ≥ 0.25 s 分句）里歌声本身的音量：只取基频各次谐波位置的能量，减去同一帧谐波之间测到的噪声（噪声 12 dB 以内几乎不影响），扣除随音高自然上升的 0.6 dB/半音，P85 − P15。差得多马上给好评；差得少要唱满 40 秒才下结论（一小段主歌里句句差不多是正常的） | ≥ 10 / 6 / 3 dB |

**伴奏检测**：用音箱放原唱（带伴奏）录进来时，音高追踪会跟着贝斯走（一段原唱测出 A#1–A#3，四分之一的帧在 E2 以下），再把乐器的频谱当成歌声来评共鸣——原唱被判成“闷”。现在比所选声部最低音还低 5 个半音以上的音不算你唱的（只看低的一侧：默认声部是男中音，不能误伤没改声部的女声高音）；这类音占有音高时间的 ≥ 8 % 就判定有伴奏：共鸣、强弱对比不评分，结果页顶部说明原因。那段原唱是 34 %，四段清唱是 0.3–1.0 %（`tests/real.test.mjs`、`tests/metrics.test.mjs`）。伴奏的音高在声部范围内时分不出来，所以仍然建议清唱。

不做判断的：唱错了音但唱得很准（没有乐谱）；节奏（不看原唱的时间轴，拍子找不可靠，已去掉）；感情对不对。伴奏和环境噪声会干扰判断，安静的地方清唱最好。共鸣只测声学结果（歌手共振峰），胸声 / 头声 / 混声等发声机制只用麦克风无法可靠判断。

音高识别在噪声、混响和气声里也能跟住歌声：波形周期性不够的帧，只要频谱里有一串高出底噪 ≥ 10 dB 的谐波（≥ 3 根、两根相邻），就算“弱”的歌声帧，但只作为正在唱的音的延续（同一音高 ±0.7 半音）或连续 3 帧同一音高才算，同时顺带纠正低八度。历史记录里有录音的旧记录，打开时会用新方法从录音重新识别。

课程“一口气唱多长”就是嗓音检查里的最长发声时间（MPT）：一口气、舒服的音高和音量，≥ 10 秒通过；成年男性平均约 26 秒、女性约 21 秒（ASHA；Maslan et al. 2011），达到平均即满分。

## 音准训练场

依据：唱不准的人多半听辨正常，问题在“听到的音 → 嗓子怎么动”的对应，典型表现是把音程唱小、音域唱窄（Pfordresher & Brown 2007；Hutchins & Peretz 2012）。所以每题都是“听了就唱”，并按研究结论安排：

| 做法 | 依据 |
|---|---|
| 目标音在舒服音区的一个八度里随机出（声部中音下 5 个半音起），题型穿插（每轮 4 跟唱 + 3 听一唱二 + 3 回声，同类不连出 3 题），刚唱过的音不马上再出 | 一个八度的宽音域训练有效、五度内无效（Pfordresher & Greenspon 2025）；穿插练比同题反复练保持得好（Stambaugh 2011） |
| 听一唱二按 mi、sol → re、la → fa、高音 do → ti、低音 sol → 低音 la、低音 ti 逐批解锁（本批最近 5 题有 4 题在 ±50 音分内） | 先大三和弦音（柯达伊教学顺序），唱准再加 |
| 回声短句 3 级：do–sol 内 3 个音的级进 / 三度 → 4 个音到四度 → 低音 sol 到高音 do、到六度；不出同音反复和三全音 | SSAP 的 4 音短句题型；逐步加大跳进 |
| 听完留 1 秒“心里唱一遍”再唱 | 脑中音像越清楚唱得越准（Pfordresher & Halpern 2013；Greenspon et al. 2025） |
| 判定线 ±50 → ±35 → ±25 → ±15 音分：同类题连续 3 题唱准收紧一级，唱错放宽一级（稳定在约 80 % 通过） | ±50 音分是研究里“唱对了音”的界线（SSAP）；3 上 1 下阶梯法 |
| 反馈渐隐：开始边唱边看音高线；最近 8 题有 6 题通过且判定线 ≤ ±35 时改为唱完才显示（盲唱），最近 6 题错 4 题再恢复 | 实时视觉反馈有效（Berglin et al. 2022），但一直开着会产生依赖（Paney & Tharp 2021） |
| 参考音默认人声“啊”（源-滤波合成，男 / 女声共振峰，放在声部的八度），可改钢琴 | 跟人声比跟乐器准（Watts & Hall 2008） |
| 唱错后自动再放一遍正确答案（听一唱二放 do 再放目标音） | 结果反馈（KR） |

判定：跟唱和听一唱二取停顿后第一个 ≥ 0.35 s 的音，从起音后 0.15 s 到 1 s 的中位音高（挑音、找音不算）；跟唱哪个八度都算对，听一唱二要唱在 do 的正确一侧（总在低八度回答的人按其习惯八度算，高音 do 除外）。回声短句用动态规划把唱的音高分成 K 段（每段音高方差最小），整句可以整体换八度，每个音都要在判定线内；每个音都偏同样多时提示“起音就偏了，音程是对的”。7 秒没唱算未作答，连续两题未作答自动暂停。

每轮小结：通过数、±50 音分以内的比例、一般偏差（中位数），以及数据够时的规律——整体偏高 / 偏低（按题的中位数，个别错题不算）、大跳（≥ 四度）唱小 / 唱大、上行和下行哪个差、哪个音区最差、最常错的音、八度错误。判定线、解锁进度和最近 30 轮记录保存在本机浏览器。

## 跟原唱唱

导入原唱的歌曲文件（mp3、m4a、wav……），戴耳机跟着唱：原唱的每个音是蓝条、标国际音名（如 A3），你是一条按准不准变色的线、橙字标你唱的音名；唱完换成整首歌的对照图和每个音的表。网址 `#/along`。

- **原唱的旋律从歌曲文件里提取，不从麦克风里分离。** 同一支麦克风里的两个人声，现成的开源工具分不可靠；歌曲文件则可以直接用 MELODIA 主旋律提取（Salamon & Gómez 2012, IEEE TASLP 20(6)），由 Essentia.js（巴塞罗那庞培法布拉大学 MTG，AGPL-3.0，`js/along/melody-worker.js` 从 jsDelivr 加载，在 Web Worker 里跑）。一首 70 秒的歌约 2.5 秒。流行歌里主旋律通常就是人声；前奏、间奏的乐器旋律也会被画出来。
- **麦克风只录你：要戴耳机。** 原唱在同一个 AudioContext 里播放，起点在录音时钟上已知；剩下的录放延迟（耳机输出 + 麦克风输入）边唱边每 2 秒、唱完再一次，用两条音高线自动对齐：找让最多帧跟着原唱旋律走的偏移，且允许整体偏高或偏低（整首唱高 60 音分的人也能对齐，只数“唱准的帧”会对错）。
- **逐个音对照**（`js/along/compare.js`）：原唱的每个音（跳过开头 80 ms 的跟进），你那段时间的中位音高，八度之外比较（男生跟女歌手低一个八度也算对，会说明）：±25 音分“准”，±50“略偏”，更多“不准”，没声音“没唱”；总结里有唱了几个、准的比例、整体偏高 / 偏低多少、最不准的几个音。
- **先把人声从伴奏里分出来（Demucs）**：伴奏一响，MELODIA 经常跟着和弦和贝斯走。所以歌曲导入后（YouTube / B 站则在唱完后），后台用 Demucs v4（Hybrid Transformer Demucs，Rouard、Massa & Défossez 2023，Meta，MIT）把人声分出来，再对人声单独跑 MELODIA；分好之前一切按混音分析，分好后自动替换并重新比对。用的是 Meta 发布的 htdemucs 权重，不训练：浏览器版 ONNX 导出 `timcsy/demucs-web-onnx`（180 MB，固定到提交 `92e33df6`，第一次用时下载、存进浏览器缓存），它的 JavaScript STFT / 逆 STFT 来自 `demucs-web@1.0.2`（MIT），由 `onnxruntime-web@1.30.0`（MIT）在 WebGPU 上跑，没有 WebGPU 时退回 CPU（WebAssembly，单线程，慢很多）。只算人声这一轨、一个声道（原包对 4 轨 × 2 声道都做逆 STFT，CPU 时间多 8 倍）。歌曲只在本机分析，不上传。实测（MacBook，Chrome，WebGPU）：43 秒的原唱 13–17 秒分完；合成测试歌（人声比伴奏低 3 dB，伴奏 = 贝斯 + 和弦 + 镲）：旋律在混音上 176 个时刻对 22 个，分离后对 160–162 个；前奏里伴奏在分出的人声里被压低 58.6 dB。共振峰 F1/F2 没有因此变准（两种方法中位误差都约 10 %），主要收益是旋律和频谱里不再混着伴奏（`js/along/separate.js`、`separate-worker.js`）。
- **频谱对照**：音高图下面，同一时刻原唱（上）和你（下）的频谱，共用一条频率轴。突出 F0、F1、F2，其余弱化：粗竖线 F0 = 基频 = 音高（标 Hz 和音名）；连着各次谐波（F0 的整数倍，峰值用抛物线插值，合成声音上误差 < 1 %）的线是包络；紫线 F1、F2 是共振峰（元音，与音高无关）；原始频谱画得很淡；重合的谐波用虚线连起来。差一个八度时，低的那个人的谐波密一倍、第 2 根谐波落在高的那个人的 F0 上——音名一样、只差八度，顶上一句话直接说出来（以及再偏高 / 偏低多少音分）。**原唱的 F1、F2**：原唱混着伴奏，直接做 LPC 会拟合整个混音，所以只取它旋律的谐波（音高 × 整数倍处的电平），用这些谐波重建一段干净的信号，再跑和你同样的 LPC（标 ≈，虚线）；合成元音 a / i / u 在 110–330 Hz 上 F2 误差 ≤ 12 %。**共鸣**：蓝色 2–4 kHz 区域标出“比低频弱多少 dB”——0–2 kHz 最强谐波减 2–4 kHz 最强谐波（歌唱功率比，Omori 1996；只算这个人声的谐波，伴奏大多不进来），越小越亮、越有穿透力，好的歌声约 10–20 dB。下面是声音显微镜的小组件：元音图（原唱和你的 F1/F2）和两人各一个推测的声道示意（舌位来自 F1/F2，咽腔来自共鸣）。原唱的音高取最近的旋律帧（MELODIA 在帧与帧之间、换气处会留空：0.1 秒以内都算），否则取这一刻所在的音；音高 > 450 Hz 时谐波太稀，F1/F2 测不了，图上直接写出原因。唱的时候实时显示（YouTube / B 站这类网页播放时，原唱的旋律每 2 秒才算一次、要晚 1–2 秒：频谱显示旋律已知的最近一刻，并注明是几秒前）；唱完点音高图任意位置看那一刻。为此你的麦克风声音和原唱的声音只在内存里暂存（`js/along/spectra.js`）。
- **相对音高（换调也算）**：整首比原唱低 / 高几个半音唱（原调太高、升降调）时，音与音之间都对，就不该全判错。自动模式下，你和原唱的整体偏差（各音中位数，八度之外）≥ 0.75 个半音就当作换调，取整到半音，每个音和原唱移调后的音比；整体只偏 30 音分这种不算换调，照样报告偏低。结果页可以切换“自动 / 按你唱的调（相对音高）/ 按原调（绝对音高）”。测试：整首低 2 个半音、其中一个音再低 60 音分 → 换调 −2，只有那个音判不准；按原调 → 全部不准。
- **只比你唱的那几句**：MELODIA 找的是“最突出的旋律”，歌手停下来时它跟着乐器走（句与句之间钢琴的引子音）。按音高稳定度分人声和乐器在测试歌里分不开（两组音内抖动中位数 14.7 vs 13.5 音分），所以用跟唱者自己：你唱的时候才有人声。你的有声帧连成句子（句内停顿 ≤ 0.5 秒），两头各放宽 0.3 秒；原唱的音有一半以上落在句子里才计分（句内漏掉的算“没唱”），其余当作伴奏，画成灰色、不计分（`phrasesOf`、`coverOf`）。代价：整句没唱会算进伴奏。
- **网页播放器**：YouTube、B站链接嵌在页面里播放（B站用官方嵌入播放器 player.bilibili.com，没有脚本控制，要自己点播放）；其他网站（音乐网站等）就在另一个标签页里放，点“开始跟唱”时在共享窗口里选那个标签页——任何网页播放器都行。
- **也可以用 YouTube**：粘贴视频链接，用 YouTube 官方嵌入播放器在页面里播放。网页读不到播放器的声音，所以点“开始跟唱”时浏览器会弹出共享窗口：选“这个标签页”并打开“同时分享标签页音频”（只有电脑版 Chrome / Edge 支持）。标签页的声音和麦克风在同一个时钟上；唱的时候每 2 秒对最近 8 秒跑一次 MELODIA（原唱的音晚 1–2 秒出现，不能提前显示接下来的音），唱完对整段再跑一次做逐音对照。声音只在内存里分析，结束就丢弃，不下载、不保存（`js/along/youtube.js`、`js/along/tabcapture.js`）。浏览器里用替身测过（标签页 = 一首歌，麦克风 = 合成的跟唱者，晚 0.3 秒、整体低 30 音分）：延迟校准为 0.31 秒，整体偏低 30 音分，唱了的音全部在 ±50 音分以内。
- 测试（`tests/along.test.mjs`，合成的跟唱者走完整分析流程）：延迟 0.25 s 找到、唱高 60 音分的那个音和没唱的音认出来、低八度全对、整首偏高 60 音分仍对齐且每个音都判不准、整首偏低 40 音分判“略偏”。浏览器里用真实歌曲（70 s 男声练习曲）测过：原唱当作跟唱者 96 % 的音判准；合成跟唱者整首偏高 60 音分 → 0 / 20 准、偏高 60；高一个八度 → 20 / 20 准、说明高一个八度。

## 咽音 / Twang

咽音练的是把会厌上方（杓会厌襞一圈）收窄。喉镜研究在 twang、belting、美声里都看到这种收窄（Yanagisawa 1989），所以它们并不互斥；对一位女歌手的测量里，twang 的 F1、F2 升高、F3 和 F5 降低、2–4 kHz 增强、声压级更高，声道形状和声源（声门闭合）都有变化（Sundberg & Thalén 2010）。麦克风看不到喉咙：课程只能找**声音里的咽音特征**，跟你自己的普通唱法比。通过表示“声音有咽音的声学特征”，不是看到了喉咙在做什么。

普通唱法和咽音很难唱在同一个音高上，而普通声音的高频比例本身就随音高变（合成声音一个八度内差 7–10 dB）。所以基准不是一个音，而是一条**滑音曲线**：普通唱法从低滑到高，记下每个音高上的值；咽音在这个范围里唱哪个音都行，和曲线上同一音高的值比。

| 步骤 | 通过标准 |
|---|---|
| 1 普通唱法滑音（基准） | 一个元音（推荐“诶”），一口气从低滑到高再滑回来，覆盖 ≥ 7 个半音（约五度）；2–4 kHz 的谐波要明显高出房间底噪；低的那段要测得出元音 |
| 2 咽音 | 在滑过的范围里任选一个音，同一个元音，**连续**保持 2 s：比同一音高的普通唱法穿透力提高 ≥ 6 dB、提高量 ≥ 0.8 × 音量增加量、纯净度不比滑音的中位数差 6 dB 以上 |
| 3 捏鼻子测试 | 捏住鼻子唱同样的咽音（音高差不多就行）：两次都和同一音高的普通唱法比，穿透力差 ≤ 4 dB、音量差 ≤ 4 dB，仍比普通唱法多 ≥ 5 dB，连续 2 s。比的是两次分开唱的声音，元音、音量或离麦克风的距离变了也会不通过，提示里会说明 |
| 4 咽音五音 | 五音放在滑过的范围里（从第 2 步的音往下两个半音起，放不下就挪进去）；每个音和同一音高的普通唱法比：穿透力多 ≥ 4 dB、不是主要靠变响、不变粗糙；测得出元音的音还要同一个元音 |

### 难度（收紧程度）

麦克风量不到杓会厌括约肌（AES）收得多紧，能量的是它的声学结果：喉上那段管子越窄，2–4 kHz 增强得越多（Sundberg 1974）。所以难度就是“比同一音高的普通唱法多出多少穿透力”，同时更不许靠变响、挤或漏气，保持得更久。课程页上选，声音显微镜用同一档：

| 难度 | 穿透力提高 | 不靠喊（提高量 ÷ 音量增加） | 纯净度下降 | 连续保持 | 五音每个音 | 捏鼻子后仍多 |
|---|---|---|---|---|---|---|
| 入门 | ≥ 6 dB | ≥ 0.8 | ≤ 6 dB | 2 s | ≥ 4 dB | ≥ 5 dB |
| 标准 | ≥ 9 dB | ≥ 1.0 | ≤ 5 dB | 3 s | ≥ 6 dB | ≥ 8 dB |
| 严格 | ≥ 12 dB | ≥ 1.2 | ≤ 4 dB | 4 s | ≥ 9 dB | ≥ 11 dB |

合成声音上：轻度咽音（约 +9 dB）只过入门；中度（约 +12–13 dB）三档都过；收得更紧、F3–F5 更靠拢的（+19–24 dB）也三档都过。这些数是本应用的设定，没有真人数据校准；进度里记下每一步是在哪一档通过的。

### 咽音检测标准（一页说明）

**只和你自己比，同一音高、同一元音**：第 1 步的普通唱法滑音给出每个音高上的基准，咽音唱在哪个音上就和哪个音比。

**前提**（任何一条不满足就**不判定**，并告诉你为什么，不会给通过）：

- 音高在滑音范围内（两端各放宽半个半音）。
- 同一个元音：F1 在基准的 0.8–1.4 倍、F2 在 0.74–1.35 倍（咽音本身也会让 F1、F2 升高一些）。测不出元音时不放行，提示“没法核对”。换元音本身就会改变高频：合成的普通“诶”比普通“啊”亮约 11 dB。
- 环境够安静：≥ 60 % 的帧里 2–4 kHz 的谐波高出房间底噪 12 dB。
- 数据齐全：旧版本留下的单音基准、不完整的曲线都会要求重做第 1 步；重做第 1 步后，之后各步的旧记录作废。

**测三个数**（相对同一音高的普通唱法）：

| 数 | 怎么算 | 意思 |
|---|---|---|
| 穿透力提高 ring | 谐波频段比 hbr = 0–2 kHz 全部谐波功率 ÷ 2–4 kHz 全部谐波功率（dB，减掉谐波之间的噪声）；ring = 曲线上的 hbr − 现在的 hbr。只算落在 k·F0 上的局部峰，别的窄带声音（电器啸叫、提示音）不算 | 2–4 kHz 相对低频变强了多少，整体音量抵消掉了 |
| 音量变化 loud | 谐波功率（减去谐波之间的噪声）比曲线上同一音高的高多少 dB | 是不是只是更响 |
| 纯净度下降 rough | 滑音的谐波/噪声比中位数 − 现在的（这个量本身随音高乱跳 ±5 dB，所以用整段中位数） | 有没有漏气或挤 |

曲线：滑音里每半个半音取 ±1 个半音内各帧的平均，取最长的连续一段；中间按音高线性插值。

**判定**（`js/analysis/twang.js` 的 `twangVerdict`，课程和声音显微镜共用；下面是“入门”档的数，其他档见上表）：

- **有咽音的声学特征**：ring ≥ 6 dB，并且 ring ≥ 0.8 × loud，并且 rough ≤ 6 dB。课程要求**连续** 2 秒：每一刻看它之前 0.5 秒的中位数，中间断了就重新计时。
- **主要是变响（像喊）**：loud ≥ 5 dB 且 ring < 0.8 × loud。
- **挤 / 气声**：rough > 6 dB，或有声音但 1.5 秒里大部分听不出音高。
- **普通**：其他情况（ring < 6）。

合成声音上（D3–C4，每半个半音，44.1 和 48 kHz）：普通唱法对自己滑音曲线的 ring 在 −1.9…+3.0 dB，全部判“普通”；咽音在 +8.8…+21.5 dB，全部判“咽音”。6 dB、0.8、5 dB、rough 6 dB 都是本应用的设定，只在合成声音上校过，没有用真人数据验证，也不是文献里的阈值。F3–F5 靠拢等共振峰变化只画出来给人看，不参与判定。

**声带闭合**（麦克风看不到声带，这是从声音推断；和同一音高的普通唱法比，`closureOf`）：

| 结果 | 声学表现 | 合成声音上 |
|---|---|---|
| 漏气（闭合不足） | 倒谱峰突出度 CPP 大幅下降（≥ 10 dB），或下降且 H1*−H2*（经共振峰校正的第一、第二谐波差，越大越“开”，Hanson 1997）升高 ≥ 2 dB | CPP −13…−15 dB，H1*−H2* +5…+8 dB；很严重时 H1、H2 被噪声淹没，只看 CPP |
| 挤（闭得紧但振动不规则） | CPP 下降，H1*−H2* 没升高 | CPP −5…−7 dB，H1*−H2* 偏低 |
| 闭合好 | CPP 没明显下降 | 咽音和“闭得紧但规则”的声音：CPP 不变，H1*−H2* 低 2–5 dB——咽音本来就闭得紧一点，不算问题 |

CPP 下降的门槛随难度：入门 4、标准 3、严格 2 dB。漏气或挤的时候不判咽音（两者都会让高频看起来变强），提示里分开说明怎么改。

**课程页的可视化**（按钮、进度条和固定高度的提示框在最上面，下面每张图高度固定，唱的过程中页面元素不会跳动）：

- 穿透力曲线：横轴音高，灰线是你的普通唱法（第 1 步的滑音），绿色虚线是这一档的通过线，白点是你现在；第 1 步滑音时显示已经覆盖了哪些音。
- 咽音还是喊：往上是更亮，往右只是更响。
- 声带闭合：横轴 H1−H2 比普通唱法的变化（左 = 更紧），纵轴周期性下降（越往下噪声越多），绿 / 黄 / 红 = 闭合好 / 漏气 / 挤。
- 频谱对比、共振峰 F1–F5。

**已知分不清的情况**：

- belting、更亮的元音变体也可能有同样的声学特征。只把 F1、F2 提高 15–20 % 的普通“啊”可能通过——而 F1、F2 升高本来也是咽音的特征之一，单凭麦克风分不开。
- 麦克风的自动增益、降噪、离麦克风的距离会改变“音量”和频谱：滑音和之后几步要用同样的设备、同样的距离。
- 周期规则的挤压不一定让纯净度下降。

### 为什么咽音用“谐波频段比”，五维评分的“共鸣”用最强谐波之比

两者都是比值（整体变响会抵消），都只数谐波、把谐波之间的房间噪声去掉。区别在音高：最强谐波之比（SPR，Omori 1996）看 2–4 kHz 里最强的那一根，音高一变，单根谐波在共振峰上滑进滑出，合成声音上差一个半音能跳 6 dB；把整段频段的谐波功率加起来，相邻音高之间就稳得多，才能拿不同音高来比。五维评分的“共鸣”是一整段歌的中位数，各种音高平均掉了，而且要和文献里的 SPR 数值（歌剧演员 11–30 dB）对得上，所以仍用 SPR。噪声：噪声只比歌声低 12 dB 时，普通“啊”的 SPR 从 31.4 变成 30.7，谐波频段比从 30.8 变成 28.1；若把谐波之间的噪声也算进去（整段能量比），会差 9 dB，足以误判成咽音。三种算法都会被气声的呼气噪声抬高，所以咽音课另查纯净度。

## 共振峰 F1–F5

共振峰不是音高。音高是基频 F0（声带每秒振动多少次）；共振峰是口腔和喉咙把声音放大的几个频段，由舌头、嘴型、喉咙形状决定，和唱多高基本无关：同一个音高唱“衣”和“啊”，F0 一样，F1 差很多；同一个“啊”换个音高，F1 基本不动。声音显微镜里画两张图：

- 元音图：横轴 F2（左 = 舌头靠前）、纵轴 F1（上 = 舌头高、嘴张得小），灰圈是 Peterson & Barney (1952) 的男 / 女声平均值（衣、诶、哎、啊、哦、乌），绿点和轨迹是现在的声音。
- 指纹图：每个发音一行，F1–F5 各一个点，粗线是 F3–F5 的跨度——在 Sundberg & Thalén（2010）测的那位歌手身上，咽音的 F3、F5 降低，这条线变短（合成的普通“啊”测得约 1360 Hz、真值 1400；咽音约 810 Hz、真值 850）。“📌 记下这个音”最多存 6 个，刷新后还在。参考元音只有 F1–F3（F4、F5 没有公认的平均值，不编造）。

测法：LPC 在约 11 kHz 上做。F1–F3 用 12 阶；12 阶只有 6 对极点，要分给 5 个共振峰和声源的整体倾斜，F5 大多测不到，而且 F4、F5 靠得近时（正是咽音）会被并成一个。所以 F4、F5 另用 16 阶，取紧跟在 F3 之后的两个极点（16 阶整体用会让 F1、F2 变差：它开始拟合谐波和声源）。合成元音（F0 110–300 Hz，44.1 / 48 kHz）上：F4 误差中位 / 90 分位 0.5 / 1.9 %（只用 12 阶是 1.8 / 5.2 %），F5 在 68 % 的帧里测到、误差 1.8 / 3.7 %（21 %，4.9 / 9.3 %），F3–F5 跨度误差 78 / 156 Hz。F5 只在那里真有声音时才算：附近的谐波比最强谐波低不超过 65 dB 且高出两侧谷底 ≥ 6 dB（“乌”那里低约 80 dB，LPC 会放一个乱跳的假极点；“啊”“衣”的 F5 约低 50–58 dB，咽音约 30）。显示的是最近 0.6 秒的中位数；F4、F5 在这段时间里离散超过 2.5 % 就不显示。宁可空着，也不画错的。

能测多高：F0 ≤ 300 Hz 测得准（实心点）；300–450 Hz 谐波太稀，只能粗略估计（空心点）；再高不显示。女声大约 D4 以上就只剩粗略值，A4 以上测不了。

## 声音显微镜里的推测

舌位：F1 越低舌越高、F2 越高舌越靠前（按声部对女声共振峰缩放 1.17）；咽腔收窄：2–4 kHz 相对基准（没设基准时用绝对值）；喉位：共振峰推算的声道长度，只和基准在同一个元音上比较；软腭：鼻音指标 A1−P0（只在低音开口元音上测得到）；声门：H1−H2 推算的开放比、周期抖动。音高 > 约 350 Hz 共振峰测不准，相关部分显示“测不了”。问题要持续约 1 秒才显示：声音闷（排除“乌/哦”这类本来就闷的元音）、气声、挤卡、喉位上提、鼻音、振动不稳。专业女声录音上不报任何问题。这是按声学规律推测的示意，不是影像。

## 方法与代码

- 采集：AudioWorklet，1024 样本一跳；分析窗 2048 样本（44.1/48 kHz 下约 46 ms），fast vibrato 不会被窗平均掉。
- 基频：YIN（FFT 实现）+ 八度纠错（奇次谐波检验）+ 3 点中值；和弦 / 过渡帧不判定。`js/dsp/`
- 音高状态：`js/analysis/pitch.js`；五维评分：`js/analysis/metrics.js`；颤音：`js/analysis/vibrato.js`
- 中英文：`js/i18n.js`。默认按 `navigator.languages`（系统和浏览器的首选语言顺序）取第一个中文或英文，都没有时用英文；设置里可手动选，切换后刷新页面。文案就地成对写成 `L('中文', 'English')`，页面静态文字用 `data-en` 属性。
- 课程与判定：`js/lessons/lessons.js`（每一步的 `check` 是纯函数）；运行：`js/lessons/runner.js`
- 音准训练：出题、判定、自适应和小结 `js/gym/drills.js`（纯函数）；页面 `js/ui/gym.js`
- 参考音：`js/audio/tone.js`；人声合成（也用于测试）：`js/audio/synth.js`
- 可复用的小组件（声音显微镜、跟唱、咽音课共用）：单个人声的频谱 `js/viz/voiceSpec.js`（F0、F1、F2、包络、2–4 kHz 共鸣，窄的画布自动用小字并避开重叠），元音图 + 迷你声道 `js/ui/voiceCards.js`（`tractOf` 从一刻的 F1/F2 和共鸣推测声道形状），频谱数据 `voiceSide`（`js/along/spectra.js`）
- 声音显微镜：推测 `js/analysis/voiceState.js`，视图 `js/viz/scope.js`（频谱对比：两条频谱都按 0–2 kHz 的最高峰对齐到 0 dB，2–4 kHz 那段的高低差就等于歌唱功率比的差），页面 `js/ui/scope.js`；咽音课在 `js/lessons/lessons.js`
- 咽音 / 喊的判定：`js/analysis/twang.js`（课程和声音显微镜共用）；白话词语解释：`js/ui/glossary.js`
- 共振峰：LPC `js/dsp/lpc.js`（F4/F5 用 16 阶，见 `upperFormants`；降采样只用帧内完整覆盖的样本——滤波器越过帧尾时，48 kHz 下会在 5 kHz 附近造出假峰）；标准元音、认元音、“同一个元音”、可信度 `js/analysis/vowels.js`；元音图和指纹图 `js/viz/formants.js`
- 跟原唱唱：旋律提取 `js/along/melody.js`、`js/along/melody-worker.js`（Essentia.js，AGPL-3.0）；对照 `js/along/compare.js`；图 `js/viz/along.js`；页面 `js/ui/along.js`
- 参考文献：`js/refs.js`（全应用统一编号；判断规则旁的 [n] 点开就是论文，各页面底部列出所用文献和一句要点）
