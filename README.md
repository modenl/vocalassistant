# 声乐练习台 VocalLab

在浏览器里用麦克风听你唱歌，只做**测得准**的判断，并告诉你下一步练什么。纯前端，无需构建；数据只保存在本机浏览器（IndexedDB）。

## 运行

```bash
python3 tools/serve.py        # → http://localhost:8765
```

麦克风需要安全环境（`localhost` 或 https）。建议关闭耳机 / 系统降噪，离麦克风 20–30 cm。

## 功能

| 模块 | 内容 |
|---|---|
| 唱一段看问题 | 实时音高轨迹（绿 = 准、黄 = 略偏、红 = 不准、灰 = 滑音；⚡ 断档、↘ 句尾掉音、↗ 挑音）、当前音与音分表、五维评分（雷达图 + 总分）；唱完给出“最需要练的 3 件事”和对应课程 |
| 基础课程 | 6 课 14 步：音准、长音与气息（含“一口气唱多长”）、滑音不断、音量控制、不喊唱、颤音。每步有参考音、目标线和一句话的通过标准，程序自动判定并打 0–100 分 |
| 历史记录 | 每次的五维评分、完整音高轨迹与录音同步回放；旧记录打开时按最新规则重新分析 |
| 设置 | 语言（中文 / English，默认跟随系统和浏览器）、声部（只决定课程练习音的音区）、A4、麦克风、噪声门限、数据导出 / 清空 |

## 五维评分（不需要原唱或乐谱）

和相对音准按“你自己的调”判断一样，节奏按“你自己的拍子”判断。每一项都有公开的计分规则（界面里“评分：…”），维度分 = 各项加权平均（有一项 < 60 时，该维度最多 74 分），总分 = 已判断维度的平均（至少 3 维、唱满 15 秒才出总分）。数据不够的项目不计分，边唱边显示进度和“还差：再唱 N 个音 / 约 N 秒”；唱够了但这类演唱判断不了的（如自由节奏）显示“无法判断”。

| 维度 | 检查 | 怎么测 | 计分（满分 / 75 / 60） |
|---|---|---|---|
| 音准 | 相对音准（×3） | 稳定的音相对你自己（±8 s 局部）的十二平均律格子的偏差，±25 音分内算准 | 唱准比例即分数 |
| | 整体偏移（×1） | 开头 ¼ 与结尾 ¼ 的整体音高（±5 s 局部调，解卷绕）之差：越唱越低 / 高 | ≤ 10 / 30 / 60 音分 |
| 节奏 | 节拍稳定 | 找拍子：把演唱的“新意曲线”（重读时音量上升 + 换到新音的音高变化 + 开口）做自相关（到 4.2 s），每个候选拍长（0.3–1 s）按 1、2、4 拍（或 1、3 拍）同时重复的强度打分——拍、两拍、小节一起作证，比逐个找字头可靠得多；强度 ≥ 5 个标准差才算找到（真实清唱 6–8，随机节奏 ≤ 4.2）。然后在 8 秒窗口里跟踪本地速度，看它的波动（稳健标准差）。找不到拍子时退回逐音方法（最常见音长的时长波动） | ≤ 1.5 % / 4 % / 7 % |
| | 速度稳定 | 同上的本地速度：后 ⅓ 比前 ⅓ 快 / 慢多少（软、连贯的演唱测量误差可达几 %，所以阈值放宽） | ≤ 3 % / 8 % / 15 % |
| 气息 | 长音稳定 | ≥ 0.8 s 的长音里，去掉颤音后的音高漂移（P10–P90） | ≤ 15 / 35 / 60 音分 |
| | 句尾掉音 | 乐句最后一个长音（≥ 0.8 s，后面停顿 ≥ 0.25 s）结束前 0.22–0.05 s 的平均音高比音身低 ≥ 30 音分；超过一个半音的快速下滑算风格（fall-off） | 掉音比例 0 / 20 % / 35 % |
| 技巧 | 断档 / 破音 | 连续发声中音高突跳 ≥ 1.5 半音并保持，同时音量反向阶跃 ≥ 5 dB（M2 比 M1 弱 8–10 dB），没有辅音式凹陷 | 每分钟 0 / 0.5 / 2 次 |
| | 喊唱 | 音量对音高的回归斜率（自然上升约 0.5–0.8 dB/半音）+ 高低音量差 | ≤ 0.8 / 1.2 / 1.6 dB/半音 |
| | 挑音 | 停顿后开口的音：开头 60 ms 比稳定后的音低 ≥ 80 音分（≤ 3 半音），用 ≥ 0.1 s 才到位 | 比例 ≤ 5 % / 25 % / 40 % |
| | 颤音 | 长音音高的频谱：速率、幅度、规律性；直音不算问题 | 有毛病的比例 0 / 30 % / 50 % |
| 表现力 | 强弱对比 | 乐句（停顿 ≥ 0.25 s 分句）平均音量，扣除随音高自然上升的 0.6 dB/半音，P85 − P15 | ≥ 10 / 6 / 3 dB |

没有乐谱测不出来的：唱错了音但唱得很准、整拍唱长 / 唱短但仍落在拍上、感情对不对。伴奏声会干扰判断，清唱最好。胸声 / 头声 / 混声等发声机制、音色、共鸣只用麦克风无法可靠判断，本应用不做判断。

课程“一口气唱多长”就是嗓音检查里的最长发声时间（MPT）：一口气、舒服的音高和音量，≥ 10 秒通过；成年男性平均约 26 秒、女性约 21 秒（ASHA；Maslan et al. 2011），达到平均即满分。

## 方法与代码

- 采集：AudioWorklet，1024 样本一跳；分析窗 2048 样本（44.1/48 kHz 下约 46 ms），fast vibrato 不会被窗平均掉。
- 基频：YIN（FFT 实现）+ 八度纠错（奇次谐波检验）+ 3 点中值；和弦 / 过渡帧不判定。`js/dsp/`
- 音高状态：`js/analysis/pitch.js`；五维评分：`js/analysis/metrics.js`；节奏（音头、拍子、速度）：`js/analysis/rhythm.js`；颤音：`js/analysis/vibrato.js`
- 中英文：`js/i18n.js`。默认按 `navigator.languages`（系统和浏览器的首选语言顺序）取第一个中文或英文，都没有时用英文；设置里可手动选，切换后刷新页面。文案就地成对写成 `L('中文', 'English')`，页面静态文字用 `data-en` 属性。
- 课程与判定：`js/lessons/lessons.js`（每一步的 `check` 是纯函数）；运行：`js/lessons/runner.js`
